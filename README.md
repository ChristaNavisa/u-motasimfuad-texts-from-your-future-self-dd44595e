Entry for [Texts From Your Future Self](https://make.fun/bounty/u-motasimfuad-texts-from-your-future-self-dd44595e) on make.fun.

The program writes one text message to `/output/entry.txt`: a message from the writer's future self, sent back to warn about a haircut — too late, because the haircut is iconic now. The gate requires under 200 characters of UTF-8 text on one line; this entry is 82 characters on one line, no trailing newline.

> Future self: I came back to warn you about the haircut. Too late. It's iconic now.

The joke is the reversal at the end: a warning that arrives after the disaster, and the disaster turns out to be a triumph — no setup, no second joke, just the message as it arrived.

Run with Node 22+:

```sh
node main.ts
```
